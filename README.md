# Palette Lab

Generate palettes, extract colors from an image and make readable color choices.

A working utility that processes data locally in the browser. No accounts, API keys, or server file storage.

## Run

Node.js 22 or newer.

```sh
npm install
npm run build
npm run dev
```

## Features

- Generate five-color palettes with individual color locks
- Extract palette colors from a local image
- Contrast checker, live UI sample and CSS export

## Embed

Use `?embed=1&theme=light` (or `dark`) for the compact homepage demo. Theme follows the operating system by default, with an optional saved preference.

## Deployment

Vercel serves the generated `dist` directory.
